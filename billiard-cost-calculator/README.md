# 당구장 운영 원가계산기

`index.html`을 브라우저로 열면 바로 사용할 수 있는 단일 파일 계산기입니다 (설치 불필요).

## 기본 입력값
- 매장 60평, 다이 18대, 영업 10:00~23:00 (13시간), 월 30일
- 권리금 5,000만원 (60개월 상각), 보증금 3,000만원 (기회비용 연 3%)
- 월세 180만원, 세금 월 200만원
- 근무자 1명, 시급 10,320원 (2026 최저시급)
- 천갈이 다이당 70만원, 주기 8년
- 월평균 매출 700만원
